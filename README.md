# Currency ExchangeRate Converter FastAPI

## 🧠 Architecture
 -FastAPI Backend  →  Live Exchange Rates API        
 -SQLite (History Storage)        
 -Streamlit Dashboard 

## ⚙️ 1. FASTAPI BACKEND
-📦 Install
- pip install fastapi uvicorn requests sqlite3

## ▶️ Run backend
- uvicorn main:app --reload

## 🎨 STREAMLIT DASHBOARD (Frontend GUI Part)
-📦 Install
-pip install streamlit requests pandas

## ▶️ Run dashboard (Frontend)
-streamlit run app.py
